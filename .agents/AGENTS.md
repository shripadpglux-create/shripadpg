# Workspace Guidelines & Rules

## Project Status Graph Rule
- **Mandatory Update Rule**: After making ANY architectural change, adding a new feature, modifying an existing component/endpoint, or deleting code, you MUST automatically update `PROJECT_STATUS_GRAPH.md`.
- **Format**: Append a new version snapshot (`### 📍 Version X.Y — Feature / Change Description`) containing a clean Mermaid flowchart node diagram reflecting the new state, while preserving all past version diagrams for comparison.
